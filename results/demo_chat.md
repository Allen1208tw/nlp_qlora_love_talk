# 多輪對話示範：微調前 vs 微調後

## 對話 1

### 微調前（原始 Qwen2.5-3B-Instruct）

```
你：我暗戀的學妹在學校咖啡廳打工，我要怎麼跟她搭話？
專家：你可以嘗試這樣：「嘿，看你人長得挺可愛的，我們班上有人說你在學校咖啡廳工作哦？」
你：她回我「你要點什麼？」
專家：那你就說：「其實是想問你想喝什麼咖啡，對吧？」
你：那她如果說「這不在菜單上」呢？
專家：那你就可以笑著補充說：「那maybe我該學學你啊！」
```

### 微調後（+ 土味情話 LoRA）

```
你：我暗戀的學妹在學校咖啡廳打工，我要怎麼跟她搭話？
專家：點餐時說：「這杯拿鐵好像跟我的心情一樣，剛開始有點苦，但越喝越香。」
你：她回我「你要點什麼？」
專家：回：「我想點一個空氣，讓我們從今天起，每天都多一些。」
你：那她如果說「這不在菜單上」呢？
專家：接：「那我們一起創造菜單吧！我想加一項：每天見面的時間。」
```

## 對話 2

### 微調前（原始 Qwen2.5-3B-Instruct）

```
你：女朋友說我都不陪她，生氣了，該怎麼哄？
專家：你可以說：「嘿，小可愛，我知道我不夠陪著你，讓我這大男人好好道歉吧！從今天起，每個晚上十點都來找我哦！」「」
你：她說「你每次都只會說好聽話」
專家：那就趕快實踐你的行動吧！比方說，給她做個愛心造型的飯菜，這樣她應該會開心一點呢。「」
你：她終於笑了，接下來要說什麼？
專家：那真是太好了！接著可以 sweet tooth 一下，說：「看來甜點是她的剋星，我这就去買！」「」
```

### 微調後（+ 土味情話 LoRA）

```
你：女朋友說我都不陪她，生氣了，該怎麼哄？
專家：給她一杯熱可可：「我今天好像變成冷飲機，只在你身邊才會變暖。」
你：她說「你每次都只會說好聽話」
專家：回「那好，從現在開始我們一起練習挑刺，然後一起把每個刺都磨成甜點。」
你：她終於笑了，接下來要說什麼？
專家：「這是我第一次看到你笑得這麼開心，以後每週都讓我見到一個不同的你。」
```

## 對話 3

### 微調前（原始 Qwen2.5-3B-Instruct）

```
你：我是資工系的，教我一句跟寫程式有關的情話。
專家：「我的心跳是算法，你是這套程序中不可或缺的一行碼。」
你：她不懂程式，聽不懂怎麼辦？
專家：那就來句老實點的：「你就像我的後端資料庫，穩固可靠，缺一不可。」
你：再來一句比較不肉麻的。
專家：可以這樣說："你的笑聲就像清新的空氣，讓我心情好極了。"
```

### 微調後（+ 土味情話 LoRA）

```
你：我是資工系的，教我一句跟寫程式有關的情話。
專家：「我的程式碼剛剛遇到一個 BUG，一直跑不出結果來，直到看到你才終於 normal 化了。」
你：她不懂程式，聽不懂怎麼辦？
專家：那就換成「你的笑是我最常執行的函式，只要被呼叫，每次都能讓我運行速度變快。」
你：再來一句比較不肉麻的。
專家：「我想幫你寫一個更新版，讓我們一起進化到更好的版本。」
```
