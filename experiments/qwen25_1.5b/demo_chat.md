# 多輪對話示範：微調前 vs 微調後

## 對話 1

### 微調前（原始 Qwen2.5-1.5B-Instruct）

```
你：我暗戀的學妹在學校咖啡廳打工，我要怎麼跟她搭話？
專家：「嘿！我剛進來的時候看到妳在那裡工作，是不是挺帥氣的？」
你：她回我「你要點什麼？」
專家：「哦，對不起，我聽錯了你的話。你在說咖啡嗎？」
你：那她如果說「這不在菜單上」呢？
專家：「那真是太可惜了，我也一直想試一下他們的拿鐵啊！」
```

### 微調後（+ 土味情話 LoRA）

```
你：我暗戀的學妹在學校咖啡廳打工，我要怎麼跟她搭話？
專家：你可以說：「剛進來就看到一杯拿鐵，裡面加了什麼？」
你：她回我「你要點什麼？」
專家：你笑著說：「點一杯冷萃，加糖不加冰，留給你喝。」
你：那她如果說「這不在菜單上」呢？
專家：那就誠懇地說：「抱歉啊，我們沒有冷萃，但我們可以合作設計一款新口味嗎？」
```

## 對話 2

### 微調前（原始 Qwen2.5-1.5B-Instruct）

```
你：女朋友說我都不陪她，生氣了，該怎麼哄？
專家：「陪你就是最好的陪伴，別擔心，我隨時準備好陪你啦！」
你：她說「你每次都只會說好聽話」
專家：「那我以後就改習慣了，每天都跟你說好聽的話啊！」「有時我也想跟你好好聊聊天，只是現在工作太多，還好嗎？」
你：她終於笑了，接下來要說什麼？
專家：「看到你的笑容我就開心，下次我們可以約個時間一起出去玩哦！」
```

### 微調後（+ 土味情話 LoRA）

```
你：女朋友說我都不陪她，生氣了，該怎麼哄？
專家：給她一杯熱可可，說：「今天冷了，喝點熱的解癮一下吧。」
你：她說「你每次都只會說好聽話」
專家：回：「那好，以後每天第一句都是『早安，今天想吃什麼？』。」
你：她終於笑了，接下來要說什麼？
專家：立刻拉她去散步，輕聲說：「這片草地是我專屬的，你敢踩嗎？」
```

## 對話 3

### 微調前（原始 Qwen2.5-1.5B-Instruct）

```
你：我是資工系的，教我一句跟寫程式有關的情話。
專家：「編程就像解謎，每一個錯誤都是關鍵的訊息。」
你：她不懂程式，聽不懂怎麼辦？
專家：「雖然她不懂，但你可以把程序當成是一場遊戲，每次錯誤都是一個新的命運開始！」
你：再來一句比較不肉麻的。
專家：「coding就是一種探索未知的方式，每一次的挑戰都像是在宇宙中尋找著自己的位置。」
```

### 微調後（+ 土味情話 LoRA）

```
你：我是資工系的，教我一句跟寫程式有關的情話。
專家：「我的程式總是出錯，直到遇到你才不會再執行。」
你：她不懂程式，聽不懂怎麼辦？
專家：那就說成：「這是你的程式，由你負責編寫，運算器是你，輸入是我的名字，運算結果是我對你的好感。」
你：再來一句比較不肉麻的。
專家：「我在看這段程式時，突然覺得自己是一台無限循環，只要按下你一聲 hello，就永遠不會結束。」
```
